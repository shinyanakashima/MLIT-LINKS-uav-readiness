# 防災・災害対応ドローン即応リソースマップ

夜間・目視外に対応した「災害対応」ドローン運用が、どの地域にどれだけ分布しているかを**推定**して可視化する静的 Web マップです。自治体の防災部局・災害協定の企画担当が、災害時に動けるドローン運用の地理的な厚みを把握するための一次スクリーニングを想定しています。

国土交通省 Project LINKS の「無人航空機飛行計画データ（2025年度）」（2024年7月〜2025年6月、約297万件）から、飛行目的「事故・災害対応等」を含む計画を抽出し、出発地（市区町村重心）ごとに集計、夜間 × 目視外 × 災害対応の重なりを**即応度スコア**として地図化します。

> **重要**: 本マップは飛行計画（**申請**）ベースの推定であり、実際の出動可能性・実飛行・各事業者の実態を保証するものではありません。出典資料はスキャン抽出のため完全性・正確性は保証されません。

## 公開

GitHub Pages で静的配信できます（外部 API キー不要）。

- リポジトリ Settings → Pages → Source を `main` ブランチ / ルートに設定。
- 地図ライブラリ（Leaflet）はリポジトリに同梱（`vendor/leaflet/`）。地図タイルのみ OpenStreetMap を利用します。
- 集計済みデータ `data/processed/readiness.json`（数百KB）だけを配信し、生データ（数GB）は配信しません。

## 主な機能

- **即応度マップ**: 市区町村の出発地重心に円マーカー。色・大きさが指標値。
- **指標切替**: 即応度スコア / 完全対応（夜間×目視外）/ 夜間対応 / 目視外対応 / 災害対応計画数。
- **能力フィルタ**: 夜間対応あり・目視外対応あり・完全対応あり、都道府県、機体の種類、北海道・十勝管内のみ。
- **ランキング**と**集計サマリ**、クリックで該当地点へズーム。

## データ処理パイプライン

### 1. 生データの取得

```bash
bash scripts/download.sh
```

CKAN の恒久リンク（リソースIDは `scripts/files.txt`）から月次 GeoJSON 16ファイル（合計 約8.7GB）を `data/raw/` に取得します。失敗時は指数バックオフで再試行します。生データは `.gitignore` 済みで、リポジトリには含めません。

### 2. 集計

```bash
pip install ijson
python3 scripts/process.py
```

`data/processed/readiness.json` を生成します。巨大ファイルのため `ijson` でストリーミング処理し、`features.item.properties` のみを走査します（飛行範囲 Polygon ジオメトリは読み込みません）。

### 処理の方針（データの癖への対応）

- **規模**: 全件約297万。市区町村集計に要約しジオメトリは破棄、出発地重心点のみ保持して軽量化。
- **フィールド名の表記ゆれ**: 末尾スペース・異体字・全半角を NFKC 正規化 + `strip()` で吸収してから参照（生キーをハードコードしない）。
- **包括申請ノイズ**: 業務目的フラグが9個以上立つ行は包括申請とみなし用途別集計から除外（災害対応フラグ付き行のフラグ立ち数分布は flags=8 を谷とする二峰型で、9〜13 がほぼ全項目=包括申請に相当）。除外件数はメタ情報に記録。
- **時系列**: 「ファイル＝対象月」を月の信頼単位とする。
- **座標の粒度**: 出発地は市区町村重心レベルの秘匿座標。粒度を上げる二次加工はしない。
- **欠損**: null 安全に処理。出発地が解析不能な行は「（出発地不明）」として集計し地図には出さない。

### 即応度スコア

各市区町村について、災害対応計画を能力で重み付けして合算します。

```
score = 3 × 完全対応（夜間 ∧ 目視外）
      + 2 × （夜間のみ ＋ 目視外のみ）
      + 1 × （夜間・目視外いずれも無し）
```

